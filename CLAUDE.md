# Notes v2 — instructions for Claude

This project was generated by the **android-app-builder** skill and must keep following its coding rules.

## Before you change code
1. Read the rule files that apply to the change in `~/.claude/skills/android-app-builder/references/rules/`
   (always `core.md`; then e.g. `compose.md`, `designsystem.md`, `i18n.md`, `testing.md`, `architecture.md`).
   If the skill isn't installed, the same rules are summarised below.
2. Look at an existing feature (e.g. `feature/noteslist`) and follow the same structure.

## Non-negotiables (summary)
- Modules: `feature/*` → `core/*` only; features never depend on each other.
- UI: `XRoute` (gets the ViewModel) + stateless `XScreen` (state in, events out). One `StateFlow<XUiState>` per ViewModel.
- Components: generic look in `core/designsystem/components` (no strings), shared app components in `core/ui`,
  feature-only UI in the feature. Features never use raw Material 3 Button/FAB/TopAppBar/Card/TextField.
- Strings: only in `core/i18n/src/main/res/values*/strings_<feature>.xml`, keys prefixed `<feature>_`, every language.
  Shared texts in `strings_common.xml`. Access via `import com.machinarium.notesv2.core.i18n.R`.
- No hard-coded colors/dp — `NotesV2Theme.spacing`, `MaterialTheme.colorScheme/typography`.
- No `!!`, no `GlobalScope`, no hard-coded Dispatchers (inject `@IoDispatcher`), no `Log`/`println`, no TODOs.
- Files ≤ 300 lines. Every ViewModel/repository/mapper has unit tests; every screen a Compose UI test.
- No lint baseline, no `@Suppress` without `// justified: <reason>`.

## Project notes
- Room is the source of truth. `NoteEntity.syncState` (SYNCED/LOCAL) and `isDeleted` protect the user's changes:
  `NoteDao.mergeRemote` only rewrites SYNCED, non-deleted rows. Keep that rule when adding a real backend.
- One-off snackbars use `SnackbarMessageEffect` from `core/ui`; don't add per-feature copies.
- Analytics: track from ViewModels through `AnalyticsTracker`; event names are constants in the ViewModel.
- Deep links resolve local ids (`DeepLinkParser` in `:app`); see SPEC.md Known exceptions.
- Keep `gradle/gradle-daemon-jvm.properties` at Java 17: detekt 1.x can't run on a newer daemon.
